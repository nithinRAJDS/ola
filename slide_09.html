Streamlit App — Ask the Data
💬 Natural-language Q&A over SQL
• Type a question in plain English
• Auto-translated to SQL against the cleaned SQLite DB
• Shows the generated SQL, the result table and an auto-selected chart
• Example question buttons for one-click answers
🧠 Two translation engines
LLM engine (if API key set) + a robust rule-based mapper covering totals, averages, counts, group-bys (date/city/vehicle/payment), top-N and trends.
📑 Three tabs
1. Ask the Data — NL → SQL Q&A
2. Data Explorer — filters + quick charts
3. Data Quality — scorecard, missingness, outliers
📦 Deliverables
app.py · nl2sql.py · build_db.py · requirements.txt · run instructions
